**KENN HOSTING** est une entreprise d'hébergement web et d'infrastructure cloud basée à Yaoundé, au Cameroun. Nous automatisons l'intégralité du parcours client : commande, paiement, mise en service et gestion du cycle de vie, pour l'hébergement web, les VPS Cloud, l'enregistrement de domaines, l'email professionnel et le déploiement d'applications depuis GitHub.

Les dépôts de cette organisation hébergent le code de nos produits internes. Ils sont privés : cet espace sert de vitrine publique à l'organisation, pas de catalogue de projets open source.
